Подключить DRF: JWT, пагинация, фильтрыbackend

Синхронизация данных
~2 недели
▼
Интеграция с Jolpica-F1 API
Написать клиент JolpicaClient с retry-логикой, rate limiting и логированиемbackend
Реализовать паттерн upsert (update_or_create) — повторный запуск таски не дублирует данныеbackend
Таска sync_seasons: загрузить все сезоны с 2018 по текущийbackend
Таска sync_races: гонки, трассы, результаты и стартовая решёткаbackend
Таска sync_drivers_constructors: пилоты, команды, привязка пилот-команда по сезонуbackend
Таска sync_pitstops: данные пит-стопов по каждой гонкеbackend
Таска sync_lap_times: времена кругов по каждой гонке (с 1996)backend
Таска sync_standings: личный зачёт и кубок конструкторовbackend
Celery и расписание
Celery Beat: каждое воскресенье в 18:00 UTC запускать sync_latest_raceinfra
Модель SyncLog: фиксировать каждый запуск (статус, время, количество записей, ошибка)БД
Обработка "данные ещё не готовы": если гонка <2ч назад — retry через 30 минутbackend
Команда manage.py sync_historical для разовой загрузки всей историиbackend
Тесты
Unit-тесты для JolpicaClient с моками: проверять retry, обработку 404, 429тест
Интеграционный тест для upsert: запустить таску дважды, проверить что записей не стало вдвое большетест
