# F1 Analytics Platform

REST API для анализа данных Формулы 1. Агрегирует исторические данные
о гонках, пилотах и командах, предоставляет аналитические эндпоинты
для сравнения статистики и визуализации трендов.

Данные синхронизируются автоматически через открытые источники.

## Стек

Python, Django, PostgreSQL, Redis, Celery, Docker
