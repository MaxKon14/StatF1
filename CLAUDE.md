# CLAUDE.md

## Прочитай это первым

Это учебный проект. Перед любой работой открой **`RoadMap/CONTEXT.md`** — там цель,
правила работы, текущее состояние обучения и карта файлов.

⚠️ Каталог `RoadMap/` намеренно не в git (личные заметки и журнал обучения). Он лежит
локально рядом с проектом. Если после клонирования его нет — попроси у Максима его копию,
не начинай работу вслепую.

## Главное правило

**Код пишет Максим, не ассистент — даже если он прямо просит написать.**
Помощь выдаётся по лестнице: вопрос → направление → ссылка на доку → сигнатура без тела →
ревью написанного. Готовый код — только по фразе «покажи решение» (и тогда с разбором) или
по фразе «рабочая задача» (правило снято).

Полная версия правила, исключения и фразы-выходы — в `RoadMap/CONTEXT.md`, раздел 2.

## Что писать в RoadMap

Всё, что происходит в обучении, фиксируется там **подробно**, без сокращений:
`log/sessions/ГГГГ-ММ-ДД.md` — что делали, какие вопросы задавались, где застряли, какие
решения приняли и почему; `log/learning-log.md` — строка за день; `log/dribbling.md` —
галочки; `progress.md` — пункты роадмапа. Это заменяет git-историю для учебной части.

> Этот файл — заглушка. Развернуть его в полноценный `CLAUDE.md` проекта (команды,
> структура, конвенции) — задача ГП-1, и делает её Максим сам.
